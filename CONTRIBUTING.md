# Contributing

Bug reports, feature requests and pull requests are welcome.

1. Open an issue describing the problem or proposed behaviour.
2. Create a branch from `main` and keep changes focused.
3. Follow Moodle coding style and include tests for behavioural changes.
4. Rebuild AMD files with Moodle Grunt when `amd/src` changes.
5. Confirm the `moodle-plugin-ci` workflow passes before requesting review.

By contributing, you agree that your work is released under GNU GPL v3 or later.
